# Non-goals

The following are out of scope for A0 and must not be inferred from the infrastructure documents:

- Implementing the Rust Core or creating premature product crates.
- Implementing inference providers, model routing, workflow execution, or the product-level skill runtime.
- Integrating Ollama, MLX, MFLUX, ComfyUI, or cloud AI APIs.
- Installing or downloading AI models.
- Building a desktop application or adding frontend, UI, or marketing-specific agents.
- Finalizing detailed public contracts without Project Owner approval.
- Creating a custom agent orchestration framework, message bus, or agent server.
- Modifying global Codex settings, GitHub rulesets, or repository protection.
- Merging pull requests, enabling auto-merge, publishing releases, or changing production state.
