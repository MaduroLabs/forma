# Project scope

## Product direction

The repository is the future Rust Core for a model-agnostic AI workflow engine. Product work will be introduced through separately approved milestones.

## A0 scope

A0 establishes repository-scoped engineering infrastructure only:

- Native Codex custom-agent definitions and verified project configuration.
- Reusable repository skills for coordination, architecture, research, implementation, review, testing, security, release, Git, and documentation.
- Root operating policy and a single source of truth for project engineering knowledge.
- Handoff protocol, architecture governance, quality gates, Git policy, templates, and A0 validation evidence.
- A native multi-agent smoke exercise that is read-only and does not implement product code.

## Future scope

Future milestones may introduce Core crates, provider abstractions, model routing, workflow execution, product-level skill runtime, persistence, SDKs, and integrations only after explicit planning and approval.
